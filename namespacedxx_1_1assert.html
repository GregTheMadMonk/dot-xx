Begin a check on a value.

Template Parameters
TFailureexception type to be thrown on failure

Checks allow to output more detailed information about a failed assertion, e.g. the values that are being compared etc. Debug/all-build behavior is similar to test:

check(42) == 43; // fires in debug build only
check[42] == 43; // fires in all builds
