template<dxx::utils::FixedString fs>
auto dxx::errors::literals::operator""_err ( )
constexprexport

Construct an error from a string literal.

Automatically creates an Error if the literal contains no format args, and returns a lambda that needs to be called with arguments to substitute into the literal before it's an Error:

test("hi"_err.what() == "hi"sv);
test("hi, {}"_err("world").what() == "hi, world"sv);

◆ operator""_errno()

template<dxx::utils::FixedString fs>
auto dxx::errors::literals::operator""_errno ( )
constexprexport

Construct an error with errno from a string literal.

Works almost identical to `operator ""_err`, but constructs Error with Errno as the first argument:

errno = EIO;
test("hi"_errno.what() == "hi (errno 5: Input/output error)"sv);
test("{}"_errno(42).what() == "42 (errno 5: Input/output error)"sv);
