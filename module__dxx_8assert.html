Detailed Description

Provides test and check function-like objects. Uses <stacktrace> to display stack trace on failure if possible.

Exports two function-like objects:

  • dxx::assert::test that asserts if the condition is true
  • dxx::assert::check that wraps a value or reference in a special "checker" object for further comparisons

All failed checks throw dxx::assert::Failure by default (customizeable)

Custom operator[] is used to invoke the same checks in all build types instead of just Debug mode builds, see documentation for test_with and check_with
